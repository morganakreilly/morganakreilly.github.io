Week 4

September 16–23, 2026

Completed

Architecture locked in

Completed this week

Architecture Meeting with Meshtastic Experts

Met with experienced Meshtastic and LoRa developers to finalize the system architecture. Key decisions made:

  • Confirmed dual-microcontroller design: RAK4631 (Meshtastic) + ESP32 (WiFi bridge)
  • Serial Module configuration: TEXTMSG mode, 38400 baud, GPS disabled (UART conflict)
  • Decided against a custom PCB for v1 — off-the-shelf modules only
  • Antenna placement is critical — must extend above the enclosure for range

Technical decisions locked in

Radio

Radio Module

RAK4631 WisBlock — US915 pre-flashed with Meshtastic firmware. Stock firmware, no modifications.

Phone link

WiFi Bridge

ESP32 — hosts the AP and web server. Users connect via browser, no app install required.

Power

Power Architecture

12V LiFePO4 main + 3.7V LiPo backup (radio only) + solar charging.

Week 1

Completed

Project formation

Project formation

Team Assembled

Auburn ECE Team 4 formed for the Capstone Design course. Six members with complementary skills in electronics, networking, and mechanical engineering.

Initial Concept

Developed the core idea: a portable, solar-powered emergency communication station using Meshtastic mesh networking for deployment when cellular networks are unavailable.

What is the Mesh Beacon?

A field-deployable communication device that:

  • Provides mesh network communication when cellular networks are down
  • Charges mobile devices via solar power
  • Can be carried and deployed by one person
  • Connects phones via WiFi (no app needed)
  • Relays messages across miles using LoRa radio

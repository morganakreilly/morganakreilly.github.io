System Architecture

Dual-Microcontroller Design

The Mesh Beacon uses two separate microcontrollers working together:

  • RAK4631 (WisBlock Core): Runs stock Meshtastic firmware. Handles all mesh networking and LoRa radio communication. Connects via Serial Module (UART) to the ESP32 bridge.
  • ESP32 WiFi Bridge: Hosts a WiFi access point and web server. Phones connect to the on-device WiFi (no app install needed) and open a browser to send/view messages and check battery status.

Why two boards? The RAK4631 has no WiFi (saves power), so the ESP32 bridge provides user-facing connectivity while keeping the mesh radio efficient and unmodified.

Power System Architecture

Main Battery

12V LiFePO4 (LFP)
• 20Ah capacity
• Safer for field use
• Rugged chemistry
• Handles rapid discharge for phone charging

Backup Battery

3.7V LiPo (RAK19007 Port P2)
• Dedicated to mesh radio
• Board charges from 5V supply
• Auto failover when main depletes
• No diode module needed

Solar Input

20W Solar Panel
• ACOPOWER HY-12M-20W
• 345×470mm (secured via straps)
• Renogy 10A PWM controller
• Mounted separately on case

Voltage Regulation

5V/USB-C Output
• Pololu 5V regulator (internal)
• 12V→5V USB-C buck converter (phone charging)
• INA219 battery monitor (tracks charge state)

Range & Antenna

Target Range: 2-5 miles per hop in Auburn/Opelika area

Critical Factor: Antenna height matters far more than transmit power. Ground-level antennas lose significant range vs. elevated ones.

  • Use coverage-prediction tools (MeshCore app) before finalizing antenna placement
  • Antenna must be able to extend above the enclosure, not just a stub on the backpack
  • Safety: NEVER power the radio without antenna attached — reflected power can damage the transmitter

Phase 2 Features (Deferred to Next Semester)

Redundancy & Failsafes

Advanced backup systems beyond basic main→backup battery fallover. Multi-level failover logic, watchdog timers, fault detection.

Universal Power Input

\"Whatever's plugged in\" power conversion. Accept multiple input voltages and automatically step to battery requirements.

Multi-Protocol Firmware

Switch between Meshtastic, MeshCore, and Reticulum protocols on one device via firmware selection. Added complexity deferred.

Custom Mobile App

Dedicated phone app. Decided against in favor of browser-based web UI — simpler, updates without app store delays.

GPS & Asset Tracking

GNSS module integration (RAK12501). Distress broadcast if unit moved. Uses accelerometer from GPS bundle.

Custom PCB

Custom-designed PCB for integrated electronics. Phase 1 uses off-the-shelf modules only to stay on schedule.
